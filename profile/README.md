## 🧩 我们在做什么 · What We Do

Windows 用户的桌面、下载文件夹总是很快变得杂乱。**EasyTidy** 用「过滤条件 + 执行动作」自由组合的规则链，把重复的整理工作交给自动化去做——移动、重命名、归档、分类，一次配置，长期生效。

Desktops and downloads folders get messy fast. **EasyTidy** lets you freely combine filter conditions and actions into rule chains — move, rename, archive, classify — configure once, run automatically from then on.

我们相信文件整理的核心引擎应该是**开源、透明、可审计**的，因此把最基础也是最重要的自动化能力放在开源核心中，交给社区共同打磨；同时也在探索面向个人用户进阶需求（例如跨设备场景）的完整产品方案。

We believe the core engine for file organization should be **open, transparent, and auditable** — so the essential automation capabilities live in our open-source core, built together with the community. Alongside that, we're also building a fuller product for individual users with more advanced needs (such as cross-device workflows).
