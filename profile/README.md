## 🧩 我们在做什么

Windows 用户的桌面、下载文件夹总是很快变得杂乱。**EasyTidy** 用「过滤条件 + 执行动作」自由组合的规则链，把重复的整理工作交给自动化去做——移动、重命名、归档、分类，一次配置，长期生效。

我们相信文件整理的核心引擎应该是**开源、透明、可审计**的，因此把最基础也是最重要的自动化能力放在开源核心中，交给社区共同打磨；同时也在探索更完整的、面向进阶需求的产品化方案。

## 🚀 快速开始

**我是普通用户，只想下载用**
👉 前往 [EasyTidy Releases](https://github.com/EasyTidy/EasyTidy/releases) 下载最新版本，或访问 [easytidy.net](https://easytidy.net) 了解完整版功能。

欢迎阅读各仓库的 `CONTRIBUTING.md`，从 `good first issue` 标签的任务开始。
