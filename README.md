# 🗂️ EasyTidy 

> **让 Windows 文件管理回归秩序。一个高效、智能的文件自动化整理与规则链工具。**

Welcome to the official home of EasyTidy! EasyTidy 是一款专为 Windows 用户打造的桌面端文件自动化整理工具。通过直观的规则链设计，帮助你彻底告别凌乱的桌面与下载文件夹，让文件井然有序。

---

## ✨ 核心特性 (Key Features)

* **🧩 规则链自动化 (Rule-Based Chaining)**：支持自由组合过滤条件与执行动作（如移动、重命名、归档等），实现复杂的文件处理逻辑。
* **⚡ 高性能原生体验 (High Performance)**：基于 WPF 与 .NET 强力驱动，极致轻量，完美融入 Windows 原生视觉体验。
* **🔒 安全可靠 (Secure & Reliable)**：本地规则运行，不泄露用户隐私，支持安全激活验证。
* **🛠️ 开源社区驱动 (Open Source Core)**：核心功能完全开源，公开透明，接受社区监督与共同打磨。
